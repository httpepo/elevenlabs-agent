# Segurança do backend

Espaço reservado para adaptadores de autenticação, autorização e assinatura
de webhooks. `server-only` já protege composição, configuração e persistência
contra imports em componentes cliente.

O painel continua disponível somente na demo de desenvolvimento. Autenticação,
autorização por visitante, assinatura de ferramentas e validação de webhook
precisam ser implementadas antes de liberar o fluxo em produção.
